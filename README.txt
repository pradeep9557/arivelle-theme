Arivelle Bloom Theme Setup

1. In WordPress dashboard, go to Appearance > Themes > Add New > Upload Theme.
2. Upload arivelle-bloom.zip and click Activate.
3. Install and activate WooCommerce from Plugins > Add New.
4. Create product categories:
   - Jhumka
   - Earrings
   - Clutches
   - Handbags
   - Combos
5. Go to Appearance > Menus and create a menu with Home, Shop, Jhumka, Earrings, Clutches, Handbags, Contact.
6. Add product photos with square or vertical images. Use clear product titles like:
   Gold Plated Kundan Jhumka Earrings for Women
7. Install these plugins for sales:
   - WooCommerce
   - Rank Math SEO
   - LiteSpeed Cache or WP Rocket
   - Razorpay for WooCommerce
   - Joinchat or Click to Chat for WhatsApp

Recommended homepage sections are already built into the theme.
